# Google Material Symbols

The SVG interface icons in this directory are unmodified Google Material Symbols downloaded from the [Material Symbols catalog](https://fonts.google.com/icons) using the filenames and default style parameters shown in each filename.

- Upstream project: https://github.com/google/material-design-icons
- License: Apache License 2.0 (`LICENSE` in this directory)
- Format shipped by QR THAT!: individual SVG assets only; no fonts are included

These third-party icons are distinct from QR THAT!'s first-party project logo assets in `icons/Logo/`.
