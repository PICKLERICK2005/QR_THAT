# QR THAT!

QR THAT! will let Firefox users turn the current page or contextual links into standard QR codes for quick transfer to another device, with local URL sanitization planned later.

The project is currently in early development.

## Temporary installation in Firefox

1. Open `about:debugging` in Firefox.
2. Select **This Firefox**.
3. Select **Load Temporary Add-on**.
4. Choose this project's `manifest.json` file.
